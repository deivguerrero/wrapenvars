# Proposal: Modernize Project to Python 3.12 & uv

## Intent

The project uses Poetry with Python ^3.8 and carries legacy dev dependencies (`black`, `flake8`) alongside their modern replacements (`ruff`). This change migrates the build toolchain from Poetry to uv, raises the minimum Python to 3.12, consolidates dev tooling, and modernizes the source code with Python 3.12 idioms.

## Scope

### In Scope
- Replace Poetry with uv for dependency management, builds, and publishing
- Set Python `>=3.12.13, <3.14`
- Modernize `wrapenvars/__init__.py` with 3.12 idioms and precise type hints
- Remove `black` and `flake8` from dev dependencies (ruff replaces both)
- Update `.pre-commit-config.yaml` to add mypy hook
- Replace `poetry.lock` with `uv.lock`

### Out of Scope
- Functional behavior changes to the 4 public functions
- API surface changes (`get_str`, `set_str`, `get_dict`, `set_dict` remain identical)
- Adding a test runner or test suite
- GitHub Actions / CI pipeline changes

## Capabilities

> This section is the CONTRACT between proposal and specs phases.
> The sdd-spec agent reads this to know exactly which spec files to create or update.

### New Capabilities
None — tooling-only change, no functional spec changes.

### Modified Capabilities
None — package API and behavior unchanged.

## Approach

1. **Rewrite `pyproject.toml`**: Remove `[tool.poetry]`, add `[project]` with PEP 621 metadata, configure `[tool.uv]`, retain existing `[tool.ruff]` and `[tool.mypy]` blocks.
2. **uv migration**: Run `uv lock` to generate `uv.lock`, remove `poetry.lock`.
3. **Code modernization**: Apply ruff autofixes, tighten type hints (`dict` → `dict[str, Any]`), use `str.encode()`/`bytes.decode()` without explicit `"utf8"` (default in 3.12), replace aliased imports with direct ones where the alias adds noise.
4. **Dev deps cleanup**: Remove `black`, `flake8`. Keep `ruff`, `mypy`, `pre-commit`.
5. **Pre-commit**: Add mypy hook after ruff hooks.

## Affected Areas

| Area | Impact | Description |
|------|--------|-------------|
| `pyproject.toml` | Rewrite | Poetry → PEP 621 + uv, updated deps, Python >=3.12.13 |
| `poetry.lock` | Removed | Replaced by `uv.lock` |
| `uv.lock` | New | Generated by `uv lock` |
| `wrapenvars/__init__.py` | Modified | 3.12 idioms, precise typing, import cleanup |
| `.pre-commit-config.yaml` | Modified | Add mypy hook |

## Risks

| Risk | Likelihood | Mitigation |
|------|------------|------------|
| PyPI publish breaks with uv | Low | Test with `uv publish --dry-run` before release |
| Type hint tightening breaks downstream consumers | Low | Run `mypy --strict` and verify no new errors |
| Encoding behavior change with default utf-8 | Low | Python 3.12 default is UTF-8, same as explicit `"utf8"` |

## Rollback Plan

Revert the commit. Poetry's `pyproject.toml` and `poetry.lock` are preserved in git history. No data migration involved.

## Dependencies

- Python 3.12.13 available via `uv python install 3.12.13`

## Success Criteria

- [ ] `uv lock` succeeds with zero runtime dependencies
- [ ] `uv build` produces a valid wheel and sdist
- [ ] `ruff check --fix && ruff format` pass with no changes
- [ ] `mypy wrapenvars` passes with no errors
- [ ] `pre-commit run --all-files` passes clean
- [ ] Package imports and all 4 public functions work identically
